# Security Policy

## Supported versions

BFS is experimental software. Security fixes are provided for the current release and the
default branch only.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting](https://github.com/metaneutrons/BFS/security/advisories/new)
to send the report and reproduction details privately.

We aim to acknowledge reports within three business days and provide an initial assessment
within ten business days. Timelines for a fix and coordinated disclosure depend on severity and
the affected release surface.
